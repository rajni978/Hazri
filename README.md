# Hazri

Every presence matters.

Hazri is a classroom attendance system for a campus whose classes run from morning until evening. This repository currently contains **Feature 1: the project foundation**. There are no accounts, no database, and no attendance records yet.

## Run it locally

Use two terminals.

```bash
cd server
npm install
npm run dev
```

```bash
cd client
npm install
npm run dev
```

Then open the URL Vite prints, usually http://localhost:5173. The API listens on http://localhost:5000.
